# 🐹 宠物小屋 — hamster-house

虚拟宠物小屋 PWA — 女儿暑假项目先行验证（[Issue #57](https://github.com/touchao123/iron-bull-ops/issues/57)）

## 技术栈

- 纯前端 PWA（HTML + CSS + JavaScript）
- localStorage 数据持久化
- PWA Manifest + Service Worker（离线可用，支持添加到主屏幕）
- GitHub Pages 部署

## 本地启动

直接用浏览器打开 `index.html` 即可，或用任何静态服务器：

```bash
npx serve .
```

## 部署

项目自动部署到 GitHub Pages。

线上地址：https://touchao123.github.io/hamster-house

## 功能

- 🐹 虚拟仓鼠（有表情变化）
- 🍎 喂食系统 + 饱腹度
- 🧹 清洁系统 + 清洁度
- 🪙 金币系统
- 🛒 商店（买装饰品）
- 🏠 房间装饰
- 📋 每日任务
- 😊 宠物心情（基于状态变化）
